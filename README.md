# Заметки команды — сайт

Одна страница: список заметок, добавление, отметка «сделано», фильтр «Все / Активные / Сделано».
Данные берёт у сервера [sdai-notes-api](https://github.com/barsukov-d/sdai-notes-api) по адресу `/api`
(vite переадресует запросы на `http://localhost:3000`, адрес меняется переменной `API_URL`).

## Запуск

```bash
pnpm install
pnpm dev          # http://0.0.0.0:5173, порт меняется переменной PORT
pnpm test
```

Сначала запустите сервер заметок на порту 3000.

Тестовый проект для демо self-developer-ai (несколько репозиториев в одном проекте).
